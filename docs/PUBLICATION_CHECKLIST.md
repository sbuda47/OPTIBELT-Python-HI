# Publication and maintenance notes

The owner selected the public repository `sbuda47/OPTIBELT-Python-HI` on 9 November
2026 and authorized publication of the prepared reproducible project. The
original research workspace and raw recordings remain separate.

## Included and excluded

The repository includes source, tests, the dashboard and streaming prototype,
the frozen model, input fingerprints, result tables and reproduction guidance.
Raw recordings, split archives, per-window generated outputs, environment
folders, credentials and private correspondence are excluded.

The README links the Mendeley collection and explains the seven-part archive,
the currently displayed embargo on the linked AC.zip release, and the need to
match the original input fingerprints. The owner identifies this collection as
the source of the local subset; equivalence with a future archive download has
not been established.

## Keeping future updates reproducible

- Preserve the frozen release and implementation byte checks. Version a changed
  method explicitly rather than silently replacing this baseline.
- Run the content audit before adding new data or generated artifacts to Git.
- Report reproduction of existing results separately from tests on new motor
  acquisitions. Keep warnings, missed faults and unsupported conditions visible.
- Link collaborators to `docs/REPRODUCING.md` and the report template. Record the
  exact Git commit used for each run.

`docs/PREPARATION_RESULTS.md` records checks performed before the initial
publication; its statements about the then-unpublished state are historical.
