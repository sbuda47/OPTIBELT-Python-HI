# Extended and historical experiments

Protocols and scripts are grouped by the experiment that produced them. Local project-root assumptions were replaced with checkout-relative resolution, while the scientific methods remain recorded. These scripts are separate from the byte-frozen core implementation and have their own provenance.

The supported extra-study route is described in `docs/REPRODUCING.md`: generate `candidate_features_v1` from all 32 admitted complete raw files, run the parallel research comparison, then the streaming experiment. The scripts use fixed output names and refuse to overwrite completed runs. They need application dependencies including pandas.

Phase-1 historical audits additionally depend on the earlier private result tree and compare exact historical hashes. They are retained for transparency, not presented as dataset-free or fresh-checkout tests. Existing dated narrative report generators are historical; check their dates/interpretation before using them for a new run.
